# Reel 001 — A calmer, warmer home

## Goal

Launch ÉLAVÉNE with an atmospheric, save-worthy introduction to the brand's visual world. This is an **organic awareness Reel**, not an ad.

- **Format:** Instagram Reel, 9:16, 1080×1920
- **Final duration:** 10–12 seconds
- **Audio:** calm instrumental / ambient audio selected in Instagram's commercial music library
- **Primary CTA:** Save this for later
- **Cover text:** A calmer, warmer home

## Publication checklist

1. Upload the exported 1080×1920 video as a Reel.
2. Set `01-hero-living-room.png` as the cover; add the cover headline exactly as above.
3. Add the caption and a relevant location only when it genuinely matches the audience/partner context.
4. Share the Reel to Stories with the poll: **“Which matters most: light / texture?”**
5. After 48 hours, record reach, average watch time, saves, shares, profile visits and follows.
